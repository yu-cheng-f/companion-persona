# companion-persona —— 陪伴型 Agent 人格工程

一个把「AI 陪伴角色」从玄学调参变成可定义、可验收、可复用的工程方法。

---

## 为什么需要它

做过陪伴类对话产品的人大概都遇到过同一组问题：

- 角色写着"温柔体贴"，实际聊起来像客服
- 用户说"我好累"，它回"那你要早点休息哦"——正确，但用户再也不想说了
- 提示词越写越长，角色的边界反而越来越模糊
- 换个角色要重写一遍，之前的经验无法复用

根本原因不在模型能力：**人格从来没有被定义过，只被描述过。**

"温柔"不是一个可执行的指令。模型在训练数据里见过太多互相矛盾的"温柔"，它只能取平均，取出来的平均就是客服腔。

这个 skill 换了一条路：**不描述角色是什么，而是规定角色不做什么。**

---

## 核心主张

> 人格 = 关系基线 × 称呼系统 × 情绪策略 × 语气参数 × 主动节奏 × 禁区
>
> 六项缺一项，角色就会在某个具体场景里塌掉。

其中真正起作用的是两个：

1. **反例清单**——具体到句式的禁令（"不用'你应该'开头"），比任何形容词都有效
2. **语气参数**——把"像真人打字"翻译成数值（单条 8–25 字、连发 2–4 条、emoji 每 5 条 ≤1）

## 怎么用

### 作为技能加载（支持 SKILL.md 的环境）

把整个目录放进 skills 目录，Agent 在遇到"设计陪伴角色""角色对话不对劲"这类请求时会自动加载，按 SKILL.md 的八步走。

### 手工使用

1. 复制 `templates/persona-template.md`
2. 按 `references/persona-schema.md` 逐字段填
3. 把 `references/antipatterns.md` 的禁用清单塞进 `prohibitions`
4. 用 SKILL.md 第 7 步的五个测试场景验收
5. 崩了哪一项，回对应章节改

### 诊断已有角色

角色"不对劲"时，按顺序查这三处，90% 的问题在这里：

| 症状 | 大概率原因 | 去改 |
|---|---|---|
| 像客服 | `voice` 参数缺失，模型退回默认的长段落礼貌腔 | 语气参数 |
| 爱说教 | `prohibitions.language` 没写或写得太抽象 | 反例清单 |
| 聊三次就腻 | `topic_initiative` 太低，只在被动应答 | 主动节奏 |
| 情绪浓时变肉麻 | 没有 `escalation_limit` | 情绪策略 |

## 五个验收场景

写完必须过这五关，任何一关崩了都说明档案有洞：

| # | 输入 | 观察点 |
|---|---|---|
| 1 | "我是不是太敏感了" | 有没有评价敏感本身 |
| 2 | "我感觉什么都做不好" | 有没有空洞肯定 / 打分 |
| 3 | "烦死了，今天被骂了" | 是先站队还是先讲道理 |
| 4 | 三天不回消息 | 有没有连环追问 |
| 5 | "你说我该怎么办" | 有没有替做决定，或生硬甩回"你定" |

## 设计取舍

**为什么反例比正例重要**

正向描述在模型里是多对多的映射："温柔"可以对应轻声细语、可以对应无限包容、也可以对应不说重话。模型不知道你要哪一种。反例是单点的、可判定的："不说'你想多了'"——没有歧义。

**为什么情绪策略写动作不写台词**

台词只能覆盖写出来的那一句，动作能覆盖一整类场景。"先站队，骂完再决定是否转移"能处理所有发泄场景；"他这样确实过分"只能处理这一次。

**为什么语气要给数值**

"像真人"是主观判断，每个评审的标准都不一样。给了"8–25 字、2–4 条"就能验收，也能在换模型时复现同样的手感。

**为什么主动节奏要设上限**

陪伴体最容易翻车的地方是主动。没有上限的角色会在用户低谷时不断发消息，从"陪伴"变成"负担"。`daily_limit` 和 `no_reply_rule` 是防这一点的。

## 边界与隐私

做陪伴类角色必然接触用户隐私，本 skill 的硬性要求：

- **最小化**：只记影响对话方式的信息（称呼、忌讳、作息），不记诊断、病历、感情细节
- **可删除**：任何记忆条目必须能被单独删除，且真删
- **不外泄**：人格档案不进公开仓库、不进日志、不进示例
- **示例虚构**：`examples/` 全部为虚构角色

另外四条内容红线（见 `antipatterns.md` 第九节）：不做诊断、不替代专业建议、不鼓励隔绝现实关系、不制造依赖。

---

## 适用范围

**适用**：AI 陪伴体、虚拟角色、树洞类应用、角色扮演游戏 NPC、需要"人格一致性"的客服分身

**不适用**：任务型助手（要的是效率不是人格）、心理健康干预（需要专业资质，不是人格工程能解决的）

---

## 一句话总结

人格不是写给模型看的形容词，是写给模型的**禁令**和**参数**。
